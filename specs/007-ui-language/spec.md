# 007 介面語言設定

狀態：專案擁有者已確認（2026-10-23）

## 目的

讓使用者在設定頁自己選擇擴充功能的介面語言，不必跟著瀏覽器語言。

## 功能需求

- **FR-1**：設定頁最上方新增「介面語言」下拉選單，選項為：
  - 跟隨瀏覽器（預設）
  - 繁體中文
  - English
- **FR-2**：「跟隨瀏覽器」時，瀏覽器語言為中文（任何中文地區）就使用繁體中文，其他語言使用英文。
- **FR-3**：選擇後立即套用到擴充功能所有介面，不需要重新整理或重新啟動瀏覽器：
  - 設定頁本身（選擇後立即換成新語言）
  - 已開啟的 YouTube 分頁中的工具列、所有面板、提示文字、說明面板、編輯模式
  - 彈出視窗（下次開啟時）
  - 之後顯示的通知
- **FR-4**：設定跟著瀏覽器帳號同步。
- **FR-5**：以下文字由瀏覽器顯示，無法由擴充功能即時改變，仍然跟隨瀏覽器語言；設定頁的下拉選單下方以一行小字說明：
  - 擴充功能在瀏覽器擴充功能管理頁中的名稱與說明
  - 工具列圖示的滑鼠提示（若瀏覽器自行顯示 manifest 中的名稱）
- **FR-6**：日期、檔案大小、時間等格式依選擇的介面語言顯示（例如檔案大小 `147.1 MB`、剩餘時間「剩餘 01:23」與 `01:23 left`）。
- **FR-7**：橋接程式回傳的錯誤訊息一律由擴充功能依錯誤代碼轉成所選語言（002 FR-6a），不顯示橋接程式或 yt-dlp 的原始英文訊息（原始訊息只寫進 console）。
- **FR-8**：之後新增其他語言時，只需要新增語言檔並在選單加一個選項，不需要修改各個介面的程式。

## 非功能需求

- **NFR-1**：切換語言不得造成工具列重新掛載或面板狀態遺失（例如已釘選的面板、進行中的下載進度維持不變）。
- **NFR-2**：任何介面文字都不得寫死在程式中，必須來自語言檔；以自動化測試檢查兩份語言檔的鍵完全一致。

## 驗收條件

- [ ] 瀏覽器為英文時，設定頁選「繁體中文」，設定頁立即變成中文；已開啟的 YouTube 分頁中的工具列提示文字、面板、說明面板都變成中文。
- [ ] 下載中切換語言，進度與面板狀態不變，文字換成新語言。
- [ ] 選回「跟隨瀏覽器」後，依瀏覽器語言顯示。
- [ ] 下載完成的通知使用所選語言。
- [ ] 兩份語言檔的鍵完全一致（自動化測試）。
- [ ] Chrome、Firefox 上都符合以上各項。
