# 008 給一般使用者的安裝與自動更新

狀態：草稿，待專案擁有者確認（含「待決定事項」）

## 目的

讓**不熟電腦的一般使用者**也能自己裝好並放心使用：
- 不需要開終端機、不需要先安裝任何開發工具（例如 Homebrew）；
- 安裝過程不出現「未識別的開發者」「可能有害」之類的警告；
- 裝好之後所有元件自動保持最新，平常完全不需要理會；
- 隨時可以清楚知道裝了什麼、做了什麼，也能輕鬆完整移除。

## 使用情境

1. **小明（只用瀏覽器上網）**：從專案網頁點「安裝」，在瀏覽器確認安裝擴充功能。打開 YouTube 點「影片」，面板說「下載影片需要安裝一個小幫手」，點「下載安裝程式」→ 雙擊下載好的安裝檔 → 一路按「繼續」→ 回到 YouTube 就能下載。
2. **日常**：擴充功能、小幫手、yt-dlp 都在背景自動更新，小明完全不知道它們存在。
3. **不想用了**：在設定頁按「移除下載功能」，或在系統的「應用程式」／「新增或移除程式」移除，所有檔案與註冊一併清除。

## 名詞

- **小幫手**：對一般使用者介面上使用的名稱，指本專案的橋接程式（技術文件中仍稱橋接程式）。使用者介面不出現「橋接程式」「原生訊息」「yt-dlp」等技術名詞，除非在「進階資訊」中。

## 功能需求

### 一、取得擴充功能

- **FR-1（Firefox／Zen）**：擴充功能經 Mozilla 簽署後提供安裝；簽署後由瀏覽器依其機制**自動更新**。（是否在 Mozilla 附加元件網站公開上架，見待決定事項 D-3。）
- **FR-2（Chrome）**：依待決定事項 D-4 的結果提供。
- **FR-3**：專案網頁（GitHub Pages 或 README 頂部）提供「安裝」入口，依訪客的瀏覽器顯示對應的安裝方式。

### 二、安裝小幫手（下載功能）

- **FR-10**：提供圖形化安裝程式，**全部內含**：小幫手、yt-dlp、deno、ffmpeg。使用者不需要另外安裝任何東西。
  - macOS：一個安裝檔（.pkg），雙擊後依系統標準安裝畫面「繼續 → 安裝」完成；支援 Apple 晶片與 Intel。
  - Windows：一個安裝程式（.exe），依標準安裝精靈「下一步 → 安裝」完成。
- **FR-11**：安裝程式只安裝給目前使用者（macOS 安裝到使用者的「應用程式支援」資料夾、Windows 安裝到使用者的 AppData），不需要系統管理員密碼；自動為 Chrome、Firefox（含 Zen）註冊。
- **FR-12**：擴充功能偵測到小幫手尚未安裝時，影片與 MP3 面板顯示：
  - 一句白話說明：「下載影片與 MP3 需要安裝一個小幫手程式，它只在你的電腦上處理影片，不會上傳任何資料。」
  - 「下載安裝程式」按鈕（依作業系統下載對應的安裝檔，來源為本專案 GitHub 正式版本）。
  - 「為什麼需要它？」展開說明（瀏覽器不允許擴充功能自己處理影片檔案）。
  - 「進階：手動安裝」連結（保留現有的腳本安裝方式）。
  - 安裝完成後，面板自動偵測到小幫手並切換成可下載的畫面（不需要按「重新檢查」；仍保留該按鈕）。
- **FR-13**：安裝程式結束時顯示完成畫面：「完成！回到 YouTube 就可以下載影片了。」並提示若瀏覽器正在下載中的頁面需要重新整理。
- **FR-14**：再次執行安裝程式時，視為修復或升級，不會重複安裝或弄壞設定。

### 三、沒有疑慮（信任）

- **FR-20**：macOS 安裝檔與其中的程式以 Apple 開發者憑證簽署並經 Apple 公證（notarization），安裝時不出現「未識別的開發者」警告。（需要 Apple Developer Program，見 D-1。）
- **FR-21**：Windows 安裝程式與其中的程式以程式碼簽章憑證簽署，降低 SmartScreen 警告。（見 D-2。）
- **FR-22**：未完成 FR-20／FR-21 前，下載頁與面板必須誠實說明會看到的警告與安全的開啟方式（附截圖），不得指示使用者關閉系統安全功能。
- **FR-23**：提供一頁白話的「隱私與安全說明」（中英文），連結出現在面板、設定頁、專案網頁：
  - 擴充功能與小幫手不收集、不上傳任何資料；只連到 YouTube 下載影片，以及到 GitHub 檢查更新。
  - 小幫手只接受擴充功能的固定指令，不開網路連接埠。
  - 安裝了哪些東西、放在哪裡、如何移除。
  - 原始碼公開的位置。
- **FR-24**：專案加入開放原始碼授權條款（見 D-5），並在 README 與說明頁標示。
- **FR-25**：設定頁新增「關於」區：各元件版本、安裝位置、隱私說明連結、「移除下載功能」按鈕。

### 四、自動更新

- **FR-30**：小幫手在瀏覽器開啟期間、每 24 小時最多檢查一次更新（不使用常駐背景程式）：
  - 小幫手本身與（Chrome 版時）擴充功能檔案：本專案 GitHub 正式版本，必須**通過簽章驗證**才替換。
  - yt-dlp、deno：官方 GitHub 正式版本，驗證官方檢查碼。
  - ffmpeg：隨小幫手的新版本一起更新（本專案正式版本中的檔案）。
- **FR-31**：更新只在沒有進行中的下載時替換；先下載到暫存、驗證、再替換，失敗時保留舊版本。
- **FR-32**：下載遇到 `YTDLP_OUTDATED`、`VERIFICATION_REQUIRED` 時，立即檢查一次 yt-dlp 更新，成功後自動重試一次。
- **FR-33**：設定頁「關於」區提供「自動更新」開關（預設開啟）與「立即檢查更新」，並顯示最近一次檢查的時間與結果。
- **FR-34**：更新失敗不打擾使用者；連續失敗 3 次以上才在下載面板顯示一行提示。
- **FR-35**：擴充功能本身仍然只連 YouTube 與小幫手；所有更新的網路連線由小幫手或瀏覽器（Firefox 的更新機制）進行。

### 五、移除

- **FR-40**：設定頁「移除下載功能」：確認後由小幫手移除自己、yt-dlp、deno、ffmpeg 與所有瀏覽器註冊、記錄檔；已下載的影片不受影響。
- **FR-41**：Windows 也可以從「設定 → 應用程式」移除；macOS 也可以執行附帶的移除程式。

### 六、進階使用者（保留）

- **FR-50**：保留現有的腳本安裝方式，並新增一行指令安裝（macOS 終端機、Windows PowerShell），放在 README 的「進階安裝」章節；同樣下載本專案正式版本並驗證簽章。
- **FR-51**：已自行以 Homebrew／winget 安裝 yt-dlp 的使用者不受影響；小幫手使用自己管理的版本，設定頁標示目前使用的版本。

### 七、發佈流程（維護者）

- **FR-60**：建立版本標籤後，GitHub Actions 自動完成：建置擴充功能與小幫手、取得 yt-dlp／deno／ffmpeg 並記錄來源與檢查碼、送 Mozilla 簽署、Apple 簽署與公證（若已設定）、Windows 簽署（若已設定）、產生安裝程式、產生並簽署檢查碼、建立 GitHub Release、更新 Firefox 與小幫手的更新資訊。
- **FR-61**：所有金鑰與憑證只存在 GitHub 加密 Secrets，不得出現在 repo 或記錄中。README 的「維護者」章節寫明第一次設定的步驟。

## 安全需求

- **SR-1**：小幫手與安裝程式只連到：本專案 GitHub、yt-dlp 與 deno 官方 GitHub、YouTube（由 yt-dlp 連線）。
- **SR-2**：從本專案下載的更新必須通過簽章驗證（公鑰內建於小幫手）；驗證失敗拒絕更新並保留舊版本。
- **SR-3**：安裝程式內含的第三方程式（yt-dlp、deno、ffmpeg）在發佈時記錄來源網址、版本與檢查碼，並列在說明頁與授權聲明中。

## 待決定事項（專案擁有者）

- **D-1 Apple 簽署與公證**：需要加入 Apple Developer Program（每年 99 美元）。沒有的話，Mac 使用者第一次開啟安裝檔會看到「無法打開，因為來自未識別的開發者」，需要依說明在「系統設定 → 隱私權與安全性」允許一次。
- **D-2 Windows 簽章**：需要程式碼簽章憑證（依類型每年約數十到數百美元，各方案的個人申請資格需另外確認）。沒有的話，會看到 SmartScreen「Windows 已保護您的電腦」，需要按「其他資訊 → 仍要執行」。
- **D-3 Firefox／Zen**：在 Mozilla 附加元件網站**公開上架**（一般使用者最熟悉、最有信任感，但需要通過審查，且名稱不能使用 YouTube 商標作為主要名稱），或只做**不公開簽署**（自行提供下載）。
- **D-4 Chrome**：Chrome 線上應用程式商店不允許 YouTube 下載工具。選項：
  1. 只提供「開發人員模式」手動載入（一般使用者不適合，Chrome 每次啟動會提示）；
  2. 另外在 Chrome 商店上架一個**不含下載功能**的版本（觀看輔助、頁面整理等），下載功能只在 Firefox／Zen 提供；
  3. 主推 Firefox／Zen，Chrome 列為進階使用者。
- **D-5 授權條款**：建議 MIT（最常見、最寬鬆）；ffmpeg 等第三方程式依其各自授權隨附聲明。
- **D-6 擴充功能名稱**：上架與一般使用者信任都需要正式名稱（不能以 YouTube 開頭）。

## 驗收條件

- [ ] 一台全新的 Mac（只有 Zen，沒有開發工具）：從專案網頁安裝擴充功能 → 點面板中的「下載安裝程式」→ 雙擊安裝 → 回到 YouTube 下載 1080p 影片，全程不需要終端機。
- [ ] 一台全新的 Windows 11 同上。
- [ ] 完成 D-1／D-2 後，安裝過程不出現系統安全警告；未完成前，說明頁與實際看到的警告一致。
- [ ] 安裝程式執行第二次不會出錯。
- [ ] 發佈新版本後，Firefox／Zen 的擴充功能與小幫手、yt-dlp 都自動更新。
- [ ] 把 yt-dlp 換成舊版並觸發 `YTDLP_OUTDATED`：自動更新並重試成功。
- [ ] 竄改下載的更新檔：簽章驗證失敗，拒絕更新，舊版本照常運作。
- [ ] 設定頁「移除下載功能」後，小幫手與所有註冊、記錄檔都被移除，已下載的影片還在。
- [ ] 隱私與安全說明頁的內容與實際行為一致。
