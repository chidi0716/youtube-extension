# 001 工具列外框與共用介面

狀態：草稿，待專案擁有者確認

## 目的

在 YouTube 影片觀看頁的播放器正下方加入一條工具列，集中放置下載與觀看輔助功能。工具列看起來要像 YouTube 原生介面的一部分。

本規格只定義工具列外框、按鈕與面板的共用行為。各按鈕的功能分別定義在：
- [`002-downloads`](../002-downloads/spec.md)：下載類按鈕
- [`003-viewing-tools`](../003-viewing-tools/spec.md)：觀看輔助類按鈕

## 使用情境

1. 使用者打開任一 YouTube 影片頁，播放器下方、影片標題上方出現工具列。
2. 使用者在 YouTube 內點其他影片（YouTube 換頁不會重新載入），工具列仍在，且所有狀態對應到新影片。
3. 使用者點工具列上的按鈕，按鈕下方展開對應的面板；再點一次、按 Esc 或點面板外面就收起。
4. 使用者按右側的 ✕，工具列隱藏；之後可以從擴充功能彈出視窗重新打開。

## 功能需求

### 出現位置

- **FR-1**：工具列只出現在影片觀看頁（網址路徑為 `/watch`）。首頁、搜尋結果、頻道頁、Shorts、內嵌播放器都不出現。
- **FR-2**：工具列位於播放器正下方、影片標題上方，寬度與播放器相同。
- **FR-3**：劇院模式、一般模式切換時，工具列跟著播放器寬度調整。全螢幕時工具列不顯示。
- **FR-4**：YouTube 換頁時，工具列不得重複出現，也不得消失；面板內容要更新為新影片的資料。
- **FR-5**：YouTube 重新繪製頁面導致工具列被移除時，要自動重新插入。

### 按鈕配置

- **FR-6**：工具列分左右兩組。
  - 左組（下載類）由左至右：影片、MP3、縮圖、字幕、截圖。
  - 右組（觀看輔助類）由左至右：深色模式、劇院模式、子母畫面、浮動播放器、循環播放、更多（⋮）、說明（?）、關閉（✕）。
- **FR-7**：每個按鈕都有提示文字（滑鼠停留時顯示）與無障礙標籤，內容為該功能名稱。
- **FR-8**：按鈕有兩種類型：
  - **面板按鈕**：點了展開面板，例如影片、MP3、縮圖、字幕、循環播放、更多、說明。
  - **切換按鈕**：點了直接開關某個狀態，例如深色模式、劇院模式、子母畫面、浮動播放器；截圖是點了直接執行。
- **FR-9**：切換按鈕在「開啟」狀態時，維持與面板按鈕展開時相同的圓形背景，讓使用者一眼看出哪些功能開著。

### 面板行為

- **FR-10**：同一時間最多只有一個面板展開。展開另一個面板時，前一個自動收起。
- **FR-11**：面板從對應按鈕的正下方展開，左緣對齊按鈕；若會超出播放器右緣，改成右緣對齊。
- **FR-12**：點同一顆按鈕、按 Esc、或點面板與工具列以外的地方，面板收起。
- **FR-13**：面板可以被「釘選」。釘選後只有再點按鈕或按面板內的取消釘選才會收起；點外面、按 Esc 都不收起。換頁時釘選的面板維持展開並更新內容。
- **FR-14**：面板內容在載入資料時顯示載入中狀態，失敗時顯示錯誤訊息與「重試」按鈕，不得空白。

### 關閉與重新開啟

- **FR-15**：按 ✕ 後工具列隱藏，此設定會被記住（跨分頁、跨重新開機）。
- **FR-16**：擴充功能彈出視窗中的「啟用」開關控制工具列是否顯示。按 ✕ 等同把這個開關關掉。

### 說明面板

- **FR-17**：說明面板列出每個按鈕的圖示、名稱與一句話說明，並有一個連結開啟擴充功能的設定頁。
- **FR-18**：說明內容完全內建於擴充功能，不開啟任何外部網站。

### 鍵盤操作

- **FR-19**：所有按鈕都能用 Tab 聚焦、用 Enter 或空白鍵觸發。面板展開時，焦點移到面板內第一個可操作的元素；收起時焦點回到按鈕。

## 外觀規格

以下描述以 YouTube 深色主題為例。淺色主題下，所有顏色都要改用 YouTube 對應的淺色變數，維持相同的層次關係。

### 工具列

- 背景透明，直接融入 YouTube 頁面背景，沒有邊框。
- 高度約 48px；按鈕之間有固定間距，左右兩組分別靠左、靠右對齊。
- 圖示為白色（主要文字色）、約 24px，線條風格（Material Symbols Outlined）。
- 滑鼠停在按鈕上時，按鈕後方出現圓形的淡灰色背景；按鈕展開或開啟時，圓形背景維持且顏色稍深。圓形直徑約 40px。

### 面板

- 深灰色背景（比頁面背景亮一階，對應 YouTube 選單的背景色），圓角約 12px，有柔和陰影。
- 內距約 16–24px，文字使用 YouTube 主要與次要文字色。
- 面板寬度依內容而定，最大不超過播放器寬度。

### 清單列（例如畫質清單）

- 每列高度約 56px，左右內距一致，欄位對齊成表格狀。
- 滑鼠停留時整列背景變亮一階，並帶圓角。
- 小標籤（例如「4K」「HD」）為灰底圓角小方塊、白色粗體小字。

### 表單元件

- 下拉選單：深色背景、細邊框、圓角，右側有向下箭頭。
- 滑桿：藍色軌道與白色圓形把手；需要時可以有兩個把手表示區間。
- 開關：膠囊形，開啟時為藍色。
- 主要按鈕：藍色背景、白字、圓角；次要按鈕：透明背景、細邊框。
- 藍色使用 YouTube 的強調色變數（例如連結或按鈕的藍色），不自訂色碼。

## 非功能需求

- **NFR-1**：工具列在影片頁載入後 1 秒內出現（以 YouTube 主要內容出現為起點）。
- **NFR-2**：工具列與面板的樣式不得影響 YouTube 原本元素的外觀或排版。
- **NFR-3**：工具列不得造成影片播放卡頓；閒置時不得有持續執行的計時器或輪詢。
- **NFR-4**：所有介面文字支援繁體中文與英文。

## 驗收條件

- [ ] 打開影片頁，工具列出現在播放器與標題之間，左右兩組按鈕順序正確。
- [ ] 在 YouTube 內連續點 5 部影片，工具列始終只有一條，面板內容對應目前影片。
- [ ] 首頁、搜尋頁、Shorts 頁都沒有工具列。
- [ ] 切換劇院模式，工具列寬度跟著變；進入全螢幕時工具列不顯示。
- [ ] 一次只能展開一個面板；Esc、點外面、再點按鈕都會收起。
- [ ] 釘選後的面板點外面不會收起，換頁後仍展開。
- [ ] 按 ✕ 後重新整理頁面，工具列仍隱藏；從彈出視窗開啟後重新出現。
- [ ] 把 YouTube 切成淺色主題，工具列與面板顏色自動跟著變。
- [ ] 只用鍵盤可以操作所有按鈕與面板。
- [ ] Chrome、Firefox 上都符合以上各項。

## 不在本次範圍

- 自訂按鈕順序或隱藏個別按鈕（列為未來功能）。
- Shorts 與內嵌播放器上的工具列。
