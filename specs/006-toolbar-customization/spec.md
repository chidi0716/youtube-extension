# 006 自訂工具列

狀態：專案擁有者已確認（2026-10-22）

## 目的

讓使用者自己決定工具列要顯示哪些工具，以及它們的順序。工具列外框見 [`001-toolbar`](../001-toolbar/spec.md)。

## 使用情境

1. 使用者很少用「循環播放」和「浮動播放器」，想把它們從工具列拿掉，讓工具列更簡潔；需要時仍能從「更多」選單找到。
2. 使用者最常用「MP3」，想把它排在最左邊。
3. 使用者想把「截圖」移到右邊那一組。
4. 使用者調亂了，想一鍵恢復預設。

## 名詞

- **工具**：工具列上的每一個按鈕（影片、MP3、縮圖、字幕、截圖、連結、深色模式、劇院模式、子母畫面、浮動播放器、循環播放、說明）。
- **固定工具**：不能隱藏、也不能移動的按鈕：「更多（⋮）」與「關閉（✕）」，永遠在工具列最右邊，順序為「更多、關閉」。
- **分隔點**：工具列中左組與右組的分界。分隔點左邊的工具靠左對齊，右邊的工具靠右對齊（在固定工具之前）。

## 功能需求

### 進入與離開編輯模式

- **FR-1**：「更多（⋮）」面板最下方新增「編輯工具列」項目；點擊後工具列進入編輯模式，「更多」面板收起。
- **FR-2**：設定頁新增「工具列」區，提供與編輯模式相同的設定能力（見 FR-20），以及「在 YouTube 上編輯」的說明。
- **FR-3**：編輯模式中，工具列右側（固定工具的位置）改為顯示三個按鈕：「完成」（主要按鈕）、「取消」、「重設為預設」。
- **FR-4**：「完成」儲存並離開編輯模式；「取消」或按 Esc 放棄這次編輯的所有變更並離開；「重設為預設」把工具列恢復成預設的工具、順序與分隔點位置，但仍停留在編輯模式，按「完成」才儲存。
- **FR-5**：編輯模式中，工具按鈕不會執行原本的功能，也不會展開面板；換頁時自動以「取消」離開編輯模式。

### 編輯模式中的操作

- **FR-10**：所有工具都會顯示，包括已隱藏的工具；已隱藏的工具以半透明呈現，並在圖示角落顯示「隱藏」標記。
- **FR-11**：每個工具上方顯示一個小的「眼睛」切換按鈕：點擊即在顯示與隱藏之間切換。
- **FR-12**：用滑鼠拖曳工具即可調整順序；拖曳時顯示插入位置的指示線，放開後其他工具依序挪位。分隔點也以一個可拖曳的直線圖示顯示，可以拖到任何兩個工具之間。
- **FR-13**：可以只用鍵盤操作：Tab 聚焦到某個工具或分隔點，←／→ 移動位置，空白鍵切換顯示／隱藏，Enter 等同「完成」。
- **FR-14**：編輯模式中工具列底部顯示一行說明：「拖曳調整順序，點眼睛圖示顯示或隱藏。隱藏的工具可以從『更多』選單使用。」

### 隱藏的工具

- **FR-15**：被隱藏的工具不出現在工具列上，但仍可以從「更多（⋮）」面板中的「其他工具」區塊使用：每個隱藏的工具以「圖示＋名稱」一列顯示，點擊的效果與在工具列上點擊相同。
  - 面板類工具（例如影片、循環播放）：點擊後收起「更多」面板，改為展開該工具的面板，面板對齊「更多」按鈕。
  - 切換類工具（例如深色模式、浮動播放器）：在列上顯示目前的開關狀態，點擊即切換。
  - 執行類工具（截圖）：點擊即執行。
- **FR-16**：沒有隱藏的工具時，「其他工具」區塊不顯示。
- **FR-17**：被隱藏的工具若有進行中的狀態（例如下載進度、循環中、浮動中），在「更多」按鈕上顯示一個小圓點提示。

### 儲存與套用

- **FR-20**：設定包含：每個工具的顯示／隱藏、工具的順序、分隔點的位置。設定跟著瀏覽器帳號同步。
- **FR-21**：完成編輯後，所有已開啟的 YouTube 分頁立即套用，不需要重新整理。
- **FR-22**：設定頁的「工具列」區以清單顯示所有工具與分隔點：每列有圖示、名稱、顯示／隱藏開關、「上移」「下移」按鈕，以及可拖曳的把手；另有「重設為預設」。在設定頁的變更即時儲存並套用到已開啟的 YouTube 分頁。
- **FR-23**：預設值：
  - 分隔點左邊：影片、MP3、縮圖、字幕、截圖、連結
  - 分隔點右邊：深色模式、劇院模式、子母畫面、浮動播放器、循環播放、說明
  - 全部顯示
- **FR-24**：之後版本新增的工具，若不在使用者的設定中，以「顯示」狀態加在其所屬預設組的最後面；已移除的工具從設定中忽略。
- **FR-25**：說明面板（001 FR-17）只列出目前工具列上顯示的工具，並在最後加一行「隱藏的工具可以從『更多』選單使用」（有隱藏工具時才顯示）。

## 外觀

- 編輯模式中，工具列背景加上淡淡的虛線外框，讓使用者知道正在編輯；工具按鈕略為放大並有輕微的可拖曳提示（游標改為拖曳手勢）。
- 「眼睛」切換按鈕為 16px 圓形小按鈕，顯示時為 `visibility` 圖示，隱藏時為 `visibility_off` 圖示（Material Symbols）。
- 分隔點以 2px 寬、與工具同高的直線表示，編輯模式外不顯示。
- 顏色一律使用 001 規定的 YouTube 顏色變數。

## 非功能需求

- **NFR-1**：編輯模式外，自訂工具列不得增加工具列的載入時間或執行中的計時器。
- **NFR-2**：設定格式要有版本號，日後調整格式時可以轉換舊設定。

## 驗收條件

- [ ] 「更多」→「編輯工具列」進入編輯模式；按「取消」或 Esc 後，工具列與進入前完全相同。
- [ ] 隱藏「循環播放」與「浮動播放器」並按「完成」：工具列不再顯示這兩個按鈕；「更多」面板出現「其他工具」區塊，從那裡可以展開循環播放面板、開關浮動播放器。
- [ ] 把「MP3」拖到最左邊、把「截圖」拖到分隔點右邊並按「完成」：順序與對齊正確，重新整理後維持，其他已開啟的 YouTube 分頁立即套用。
- [ ] 只用鍵盤完成一次移動與隱藏。
- [ ] 「重設為預設」後按「完成」，回到預設狀態。
- [ ] 設定頁「工具列」區的上移、下移、開關與拖曳都能使用，變更立即反映到已開啟的 YouTube 分頁。
- [ ] 隱藏的工具正在下載或循環時，「更多」按鈕顯示提示圓點。
- [ ] 編輯模式中換頁，自動取消編輯。
- [ ] 說明面板只列出顯示中的工具。
- [ ] Chrome、Firefox 上都符合以上各項。

## 不在本次範圍

- 調整「更多」與「關閉」的位置或隱藏它們。
- 為不同頁面或不同頻道設定不同的工具列。
