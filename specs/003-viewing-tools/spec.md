# 003 觀看輔助功能

狀態：草稿，待專案擁有者確認

## 目的

工具列右組提供改善觀看體驗的功能。這些功能完全在擴充功能內完成，不需要橋接程式。

工具列外框與面板的共用行為見 [`001-toolbar`](../001-toolbar/spec.md)。

## 共通需求

- **FR-1**：除非另有說明，每個功能的開關狀態都會被記住，下次打開影片頁時自動套用。
- **FR-2**：功能開啟時，對應的切換按鈕顯示「開啟」狀態（見 001 FR-9）。
- **FR-3**：YouTube 換頁後，已開啟的功能在新影片上繼續生效。
- **FR-4**：任何功能失效（例如 YouTube 改版找不到元素）時，不得影響影片播放與 YouTube 其他功能。

## 深色模式（切換按鈕）

- **FR-10**：開啟時把 YouTube 切換為深色主題，關閉時切回淺色主題。
- **FR-11**：使用 YouTube 本身的深色主題，不自行覆寫整頁顏色。
- **FR-12**：按鈕狀態反映 YouTube 目前的實際主題；使用者從 YouTube 自己的選單切換主題時，按鈕狀態跟著更新。

## 劇院模式（切換按鈕，燈泡圖示）

- **FR-20**：開啟時，播放器以外的整個頁面蓋上一層半透明黑色遮罩（約 90% 不透明），讓畫面只剩影片；工具列本身仍可見可用。
- **FR-21**：點遮罩任何地方或按 Esc 可關閉。
- **FR-22**：此功能不記住狀態；每次打開影片頁預設關閉。
- **FR-23**：與 YouTube 自己的「劇院模式」（加寬播放器）互不干擾，兩者可以同時使用。

## 子母畫面（切換按鈕）

- **FR-30**：開啟時使用瀏覽器原生的子母畫面，影片在獨立的小視窗中播放。
- **FR-31**：使用者從子母畫面視窗本身關閉時，按鈕狀態同步變成關閉。
- **FR-32**：瀏覽器不支援原生子母畫面時（例如部分 Firefox 設定），按鈕停用並在提示文字中說明原因。
- **FR-33**：此功能不記住狀態。

## 浮動播放器（切換按鈕）

- **FR-40**：開啟後，當使用者往下捲動、播放器捲出畫面時，播放器縮小並固定在畫面右下角繼續播放；捲回播放器原位置時恢復原狀。
- **FR-41**：浮動中的播放器可以用滑鼠拖到畫面其他角落，放開時自動貼齊最近的角落；位置會被記住。
- **FR-42**：浮動中的播放器右上角有 ✕，按下後暫時回到原位置，直到下次捲動離開播放器。
- **FR-43**：浮動播放器寬度約為視窗寬度的 25%（最小 320px），維持影片比例。
- **FR-44**：只用 CSS 與擴充功能內建的程式實作，不引入任何外部函式庫。

## 循環播放（面板按鈕）

- **FR-50**：面板提供兩種模式（單選）：
  1. **重複整部影片 N 次**：輸入 1–99 的次數，或選「無限」；
  2. **循環片段**：與 002 MP3 面板相同的區間滑桿與「開始」「結束」輸入框，影片播到結束時間時跳回開始時間。
- **FR-51**：面板有「開始循環」與「停止」按鈕；循環進行中，面板顯示「已播放 X 次」。
- **FR-52**：循環進行中，按鈕顯示開啟狀態。
- **FR-53**：換到另一部影片時循環自動停止；此功能不記住狀態。

## 更多（⋮，面板按鈕）

面板以清單呈現以下開關，每項左側為圖示與名稱、下方一行灰色小字說明、右側為開關。

- **FR-60 切換分頁時自動暫停**：開啟後，切換到其他分頁或視窗最小化時影片暫停；回到這個分頁時，只有原本是被這個功能暫停的影片才會自動繼續播放。
- **FR-61 自動播放下一部**：直接控制 YouTube 本身的「自動播放」開關，狀態與 YouTube 介面同步。
- **FR-62 純音訊模式**：開啟後，播放器畫面改為顯示影片縮圖，聲音照常播放。（本功能只隱藏畫面，不保證節省頻寬，並在說明文字中寫明。）
- **FR-63 滑鼠滾輪調整音量**：開啟後，游標在播放器上滾動滾輪可調整音量，每格 5%，並在播放器中央短暫顯示目前音量；游標不在播放器上時，滾輪照常捲動頁面。
- **FR-64 隱藏留言**：開啟後隱藏留言區；關閉時恢復。

## 驗收條件

- [ ] 深色模式按鈕可切換 YouTube 主題，從 YouTube 選單切換時按鈕狀態同步。
- [ ] 劇院模式開啟後，除了播放器與工具列都被遮罩；點遮罩或 Esc 關閉。
- [ ] 子母畫面可開啟，從小視窗關閉時按鈕狀態同步。
- [ ] 浮動播放器在捲動時出現於右下角，可拖到其他角落並記住位置，重新整理後位置仍正確。
- [ ] 循環「3 次」播完第 3 次後停止；循環片段 00:10–00:20 會一直在這段重複。
- [ ] 切換分頁時影片暫停、回來時繼續；原本就暫停的影片回來時不會自動播放。
- [ ] 自動播放開關與 YouTube 自身開關同步。
- [ ] 純音訊模式顯示縮圖、有聲音。
- [ ] 滾輪在播放器上調整音量，在播放器外捲動頁面。
- [ ] 隱藏留言開啟後重新整理，留言區仍隱藏。
- [ ] Chrome、Firefox 上都符合以上各項。

## 不在本次範圍

- 觀看時搜尋其他影片。
- 自訂工具列按鈕順序與顯示。
