# 階段 6：自訂工具列（T32、T33、T34）

日期：2026-10-22　負責：實作方　規格：[`006-toolbar-customization`](../006-toolbar-customization/spec.md)、plan 3.7.3

## T32 設定模型與工具註冊表

- **設定模型**（`utils/toolbar-layout.ts`，純函式，有單元測試）：`sync:toolbarLayout` 為
  `{ version: 1, items: Array<{ id: ToolId | 'separator', visible: boolean }> }`；`null` 表示預設值。
  - 預設（FR-23）：影片、MP3、縮圖、字幕、截圖、連結｜分隔點｜深色模式、劇院模式、子母畫面、浮動播放器、循環播放、說明，全部顯示。
  - 讀取時驗證並合併（FR-24、NFR-2）：不是物件、沒有版本號或版本號不認得 → 預設值；不認得的工具（已移除）、固定工具、重複項目、
    不是物件的項目忽略；`visible` 不是布林值視為顯示；分隔點永遠顯示，沒有時加在最後；設定中沒有的工具以顯示狀態加在其預設組的最後面
    （左組在分隔點前，右組在最後）。最多讀 100 個項目。
  - 操作：`splitLayout`（左組、右組、隱藏）、`moveItem`、`stepItem`（鍵盤與上移／下移）、`toggleVisible`、`dropIndex`（拖曳的插入位置）。
- **工具註冊表**（`components/toolbar/buttons.ts`）：每個工具的識別字串、圖示、名稱、說明、類型（面板／切換／執行）；
  固定工具「更多」「關閉」另列。工具列、編輯模式、「其他工具」、說明面板與設定頁都從註冊表與設定產生。
- **工具列**：依設定排出左組與右組，右組之後固定為「更多」「關閉」（006「固定工具」）。設定改變時（其他分頁、設定頁、同步）立即重新繪製
  （`toolbarLayout.watch`，FR-21）。編輯模式外沒有新增計時器或監聽器（NFR-1）。
- **「更多」面板**：上方為「其他工具」（FR-15、FR-16，沒有隱藏的工具時不顯示），最下方為「編輯工具列」（FR-1）。
  - 面板類：收起「更多」並展開該工具的面板；因為工具列上沒有它的按鈕，面板以「更多」按鈕定位（右緣對齊），收起後焦點回到「更多」。
  - 切換類：列上是開關，顯示目前狀態；不能使用時顯示原因。
  - 執行類（截圖）：點擊即執行，完成或錯誤的提示顯示在列上，面板不收起。
- **提示圓點**（FR-17）：隱藏的工具下載中（含不確定進度）、循環中、劇院模式／子母畫面／浮動播放器開啟中時，「更多」按鈕右上角顯示藍色圓點，
  無障礙標籤加上「有隱藏的工具正在使用中」；「其他工具」中對應的列也有圓點。深色模式是長期的外觀設定，不算進行中（QUESTIONS Q48）。
- **說明面板**（FR-25）：只列出工具列上顯示的工具（含「更多」「關閉」），有隱藏的工具時最後一行說明可以從「更多」使用。

## T33 編輯模式

- 「更多」→「編輯工具列」：收起面板（釘選的也收起），工具列改為編輯模式，焦點移到第一個工具。暫存的設定只存在工具列元件中，
  「完成」才寫入 storage（FR-4）；「取消」、Esc（只在編輯模式中於 document 的 capture 階段監聽）放棄變更；
  「重設為預設」換成預設值但停留在編輯模式；換頁（影片 ID 改變）自動取消（FR-5）。離開後焦點回到「更多」。
- 編輯模式中的工具是另外的按鈕，不會執行功能或展開面板（FR-5）。隱藏的工具半透明、右下角有 `visibility_off` 標記（FR-10）；
  每個工具上方有 16px 的圓形眼睛按鈕（`visibility`／`visibility_off`，FR-11）；分隔點為 2px 寬、與工具同高的直線，可以拖曳。
- 拖曳（FR-12）：Pointer Events 自行實作（`setPointerCapture`），移動超過 4px 才開始；拖曳中只移動該項目並顯示插入位置的藍色指示線，
  放開時才改變暫存的順序。
- 鍵盤（FR-13）：工具與分隔點是可聚焦的按鈕（眼睛按鈕不在 Tab 順序中）；←／→ 移動一格並保留焦點，空白鍵切換顯示／隱藏，Enter 等同「完成」。
  操作說明以 `aria-describedby` 提供，移動與切換後以 `aria-live` 讀出結果。
- 外觀：虛線外框、工具略為放大（`scale(1.08)`）且游標為拖曳手勢；顏色只用 001 的 YouTube 顏色變數。
  工具列不夠寬時，「重設為預設」「取消」「完成」換到下一行並靠右（QUESTIONS Q49）。
- 其他分頁在編輯中改變設定：本分頁保留自己的暫存，按「完成」時以自己的結果覆寫（plan 3.7.3）。

## T34 設定頁的「工具列」區

`entrypoints/options/toolbar.ts`（DOM API，沒有 innerHTML；圖示以 `createIconElement` 建立 SVG）：

- 放在設定頁最上方：說明（含「在 YouTube 上編輯」：「更多」→「編輯工具列」，FR-2），清單每列有拖曳把手、圖示、名稱、顯示／隱藏開關、
  上移、下移；分隔點也是一列（「分隔點：上方為左組，下方為右組」）；「重設為預設」（已是預設時停用）。
- 變更立即寫入 `sync:toolbarLayout`，已開啟的 YouTube 分頁立即套用（FR-22）；在 YouTube 上編輯或同步時清單跟著更新（拖曳中不打斷），
  重新繪製後焦點回到同一個控制項。
- 拖曳把手：Pointer Events（上下），拖曳中顯示插入位置的指示線；鍵盤在把手上按 ↑／↓ 移動。
