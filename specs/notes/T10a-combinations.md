# T10a 觀看輔助功能組合測試

日期：2026-10-22　負責：實作方

依 003 FR-90 與 constitution 第 7b 點，在假觀看頁（`spikes/stage1-smoke/viewing-test.mjs` 的 T10a）加入兩兩組合的自動化檢查。每組以兩種順序開啟（A→B、B→A），每種順序檢查：

1. 開啟後：兩個功能都有作用；播放器容器在原位、尺寸不變、沒有浮動；播放器中央的 `elementFromPoint` 是播放器；播放器沒有變暗；工具列按鈕位置的 `elementFromPoint` 是工具列。
2. 組合中有浮動播放器時往下捲：
   - 劇院模式期間不浮出（FR-45）；
   - 其他情況浮到右下角（320×180），播放器沒被遮住、沒變暗，浮動控制列存在。
3. 依相反順序關閉後：所有功能都關閉，播放器回到原位，工具列可見。

各功能「有作用」的判斷：

| 功能 | 判斷方式 |
|---|---|
| 劇院模式 | `<html>` 有 class，右側欄實際不透明度 ≤ 0.1 |
| 浮動播放器 | 按鈕為開啟 |
| 循環播放 | 「重複 99 次」進行中，按鈕為開啟 |
| 純音訊模式 | `<video>` 透明、容器顯示縮圖 |
| 子母畫面 | `document.pictureInPictureElement` 是影片 |

## 組合與結果（40 項全部通過）

| 組合 | 兩種順序 |
|---|---|
| 劇院模式＋浮動播放器 | 通過（捲動時不浮出） |
| 劇院模式＋循環播放 | 通過 |
| 浮動播放器＋純音訊模式 | 通過（浮動中仍顯示縮圖） |
| 浮動播放器＋子母畫面 | 通過（子母畫面中仍可浮動） |
| 劇院模式＋純音訊模式 | 通過 |
| 劇院模式＋子母畫面（額外） | 通過 |
| 浮動播放器＋循環播放（額外） | 通過 |
| 純音訊模式＋子母畫面（額外） | 通過 |

劇院模式＋浮動播放器的細部情境（正在浮動時開劇院模式、YouTube 自己的劇院模式切換）另見 T08a（`specs/notes/T08a-cinema-floating.md`）。

## 發現的問題

- 除了 T08a 已修正的兩個問題（YouTube 劇院模式切換會讓播放器浮出、劇院模式期間仍會浮動），組合測試沒有發現其他問題。
- 測試本身的注意事項：Playwright 點擊面板中的按鈕時會先把面板捲到畫面內（例如循環播放的「開始循環」），會改變捲動位置。組合測試在檢查前捲回頂端，避免把測試造成的捲動誤判為功能問題。
